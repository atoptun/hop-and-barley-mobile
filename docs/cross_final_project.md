# Final Project

Для залучення нових користувачів до нашого додатку, ми вирішили додати новий екран, який дозволяє
користувачам переглядати різноманітні рецепти пива. Цей екран надає можливість користувачам
знаходити рецепти за різними критеріями, такими як назва та складність приготування. Для реалізації
цього функціоналу створено низка компонентів, які відповідають за відображення списку рецептів та їх
фільтрацію, а також за сортування та пошук. Користувачі можуть легко переглядати детальну інформацію
про рецепти і додавати інгредієнти до кошика. Доступ до екрану зроблений через TabBar, що дозволяє
користувачам швидко переходити до цього розділу. З метою розвантаження TabBar розділ Profle
перенесено в Drawer. Таким чином, в TabBar залишилися лише основні розділи додатку, такі як каталог
товарів, кошик та рецепти. Це дозволяє користувачам швидко знаходити потрібний розділ і зручно
переміщатися між ними. Для емуляції бекенду використаний сервіс MockAPI.io. Для отримання даних про
рецепти використаний RTK Query, що дозволяє ефективно працювати з асинхронними запитами та
кешуванням даних.
